## Getting Started

### View Notebooks

Open any `.ipynb` file on GitHub to view its code and saved outputs.

### Run Locally

1. Install Python and VS Code.
2. Clone the repository:

   git clone https://github.com/42111392-vendhan/GenAi_Python_Progress.git

3. Open the downloaded project folder in VS Code.
4. Install the Python and Jupyter extensions.
5. Open a notebook and select a Python kernel.
6. Run the cells to explore the examples.
